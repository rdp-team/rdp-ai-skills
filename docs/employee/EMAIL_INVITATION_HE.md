# נוסח מייל לעובדי RDP

**נושא:** הזמנה ל־GitHub של RDP ותיאום מפגש קצר

שלום,

נשלחה אליך הזמנה להצטרף לארגון RDP ב־GitHub. דרך GitHub נעבוד בצורה מסודרת ומשותפת עם פרויקטים, Claude Code ו־Skills ארגוניים.

אם כבר יש לך חשבון GitHub, יש לפתוח את ההזמנה ולאשר אותה. אם אין לך חשבון, ניתן ליצור חשבון ב־<https://github.com/signup> באמצעות כתובת המייל של RDP, לאמת את הכתובת ואז לאשר את ההזמנה.

לאחר האישור ניתן לפתוח את מדריך ההתקנה המלא:
<https://github.com/rdp-team/rdp-ai-skills/blob/codex/rdp-employee-skills/docs/employee/GITHUB_AND_CLAUDE_SETUP_HE.md>

נבצע גם מפגש קצר בשבוע הבא. נא להשיב איזה יום נוח יותר — יום שלישי, 15.9, או יום רביעי, 16.9 — ובאיזו שעה. מי שרוצה הסבר קצר לפני המפגש יכול לכתוב בתשובה “אשמח להסבר קצר”.

אין צורך בניסיון קודם ב־GitHub.

תודה,
