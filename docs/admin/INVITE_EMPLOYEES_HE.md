# מדריך מנהל — הזמנת עובדים לארגון RDP

## קובץ הקלט

שומרים מחוץ ל־Repository קובץ CSV מקומי. אין לבצע לו Commit.

```csv
name,email,github_username
ישראל ישראלי,israel@rdp.co.il,
עובדת קיימת,worker@rdp.co.il,existing-github-user
```

כאשר שם המשתמש ידוע, ממלאים אותו כדי שהכלי יזהה חברים קיימים. כתובת מייל לבדה אינה מאפשרת ל־GitHub לחשוף בוודאות איזה חבר קיים משתמש בה.

## בדיקה ושליחה

תחילה מבצעים תצוגה מקדימה:

```text
python scripts/invite_members.py /path/to/employees.csv
```

הדוח מסתיר את רוב כתובת המייל ואינו שומר Token. לאחר בדיקת הרשימה:

```text
python scripts/invite_members.py /path/to/employees.csv --execute
```

הכלי שולח הזמנות בתפקיד `direct_member`, מדלג על שמות משתמש שכבר חברים ועל כתובות עם הזמנה ממתינה. כשל נקודתי מסומן לבדיקה ואינו גורם לשדרוג הרשאות.

הזמנות GitHub תקפות לשבעה ימים. לאחר הקבלה יש לתת הרשאת כתיבה רק למאגרי הפרויקט המתאימים; הרשאת הקריאה הארגונית מספיקה להורדת חבילת ה־Skills. אין להפוך עובדים לבעלי הארגון כחלק מתהליך ההזמנה.

## מעקב

```text
gh api orgs/rdp-team/invitations
gh api orgs/rdp-team/members --paginate
```

בודקים מי עדיין ממתין, שולחים תזכורת לפני פקיעת ההזמנה ומאשרים שלעובד יש גישה רק לפרויקטים שלו. רשימת המיילים נשארת מחוץ ל־GitHub.
